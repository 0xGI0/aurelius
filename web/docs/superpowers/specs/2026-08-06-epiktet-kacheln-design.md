# Epiktet-Kapitel als Kacheln — Design

**Datum:** 2026-08-06 · **Status:** Vom Nutzer freigegeben · Web + Android.

Im Bücher-Tab werden Epiktets 53 Kapitel statt als schlichte Textzeilen in
derselben Kachel-Bauart dargestellt wie die Abschnitts-Zeilen der
Buch-Ansicht: Karte (Card-Hintergrund, 1er-Rahmen, Radius 12), links die
Kapitelnummer in Akzentfarbe, daneben die zweizeilige Textvorschau in der
gewählten Zitatsprache. Tap-Ziel unverändert (`read/e-N`). Android erhält
die identische Optik im BooksScreen (cardShape/colors wie Aurel-/
Seneca-Zeilen); das fährt ohne eigenes Release beim nächsten mit.
